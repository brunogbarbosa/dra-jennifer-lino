# Dra. Jennifer Lino

Site editorial de estética avançada e harmonização facial no Recreio, Rio de Janeiro. Adaptado do template Premium Vendas V4, com retratos e resultados fornecidos para este projeto, galeria comparativa, navegação responsiva e favicon personalizado.

## Desenvolvimento

Requer Node.js 20.9 ou superior.

```sh
npm ci
npm run dev
```

## Verificação

```sh
npm run typecheck
npm run build
```

## Vercel

Importe este repositório na Vercel. Framework: Next.js. Diretório raiz: `./`. Os comandos padrão de instalação e build são suficientes. Não há variáveis de ambiente obrigatórias.

## Conteúdo

Identidade, textos, contato e galeria estão em `data/site.ts`. O agendamento usa o link público de WhatsApp presente na página `bio.site/drajenniferlino`; o perfil público é `@dra.jenniferlino`. A localização exibida é Recreio, Rio de Janeiro. O registro profissional não foi incluído porque os anexos mostram números divergentes.

As fotografias fornecidas foram convertidas para WebP, sem retoque. Os resultados são individuais. O favicon está em `app/icon.svg`. A imagem OG fornecida está em `public/og-jennifer-lino.jpg`, otimizada para 1200 × 630 px.
